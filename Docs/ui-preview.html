怎么核对风格
  • 全屏只有一个强调色（#3B7DFF），没有第二个彩色到处跑；分类靠图标区分，不靠彩虹色。
  • 数字全用圆体 + tabular，跳数时不抖；单位小一号、灰一档，用来衬托数字而不是抢戏。
  • 一张卡片里不套小卡片：指标用 1px 竖线切三段，收藏用胶囊标签。
  • 圆角只有三档：卡片 22 / 控件 14 / 按钮 18；按钮统一 56 高，拇指够得着。
  • 颜色都压在深底上，靠透明度分层（surface 13% → raised 19% → secondary 22%），没有一块是纯黑。
